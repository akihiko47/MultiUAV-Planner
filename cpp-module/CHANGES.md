# Изменения поставки

Изменены или добавлены только файлы внутри `cpp-module/**`.

Главные изменения: JSON boundary и domain models, геометрия/маршрутизация,
галсы и GSD, вылеты/расписание/безопасность, независимые тесты, vendored
зависимости, копия no-fly-zons и её встраивание для существующего Docker.

Исходные test-data оставлены без изменения. Документация и новые тестовые
сценарии находятся внутри cpp-module. Подробности: README.md и VALIDATION.md.
